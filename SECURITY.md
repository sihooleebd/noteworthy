# Security Policy

## Official Source
The only official source for this software is:
https://github.com/your-username/noteworthy

## Verifying Integrity
If you suspect you have downloaded a compromised version:
1. Check that the `git remote -v` points to our official URL.
2. Compare the `COMMIT_HASH` with our main branch.

## Reporting Vulnerabilities
If you find a malware copy of this repo, please report it to GitHub immediately and open an issue in this repository to warn others.
