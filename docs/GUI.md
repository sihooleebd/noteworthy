# Noteworthy GUI

The graphical user interface for Noteworthy provides a modern, collaborative environment for editing Typst projects.

## Features

### Real-time Collaboration
- **Presence**: See who else is currently online.
- **Cursors**: View other users' cursor positions and selections in real-time.
- **Edits**: Concurrent editing with immediate synchronization.
- **Nicknames**: Set a session-specific display name in the **Session** configuration tab.

### Module Configuration
- **Visual Settings**: Configure module options (e.g., Block Design) using a graphical form.
- **Validation**: Inputs are validated against the module's `blueprint.json`.
- **Persistence**: Settings are saved to `config/modules/<module>.json`.

### File Management
- **File Tree**: Navigate your project structure.
- **Icons**: Visual indicators for folders and files.

### Interactive Build
- **Build Modal**: Select specific chapters to build.
- **Progress**: visual progress bar for build status.
